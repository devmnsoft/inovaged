# Simplificação da navegação

A navegação de administrador passou de uma lista plana de áreas técnicas para seis grupos: **Visão Geral**, **Gestão Documental**, **Arquivo Físico**, **Atendimento**, **Governança** e **Administração**. Cada grupo usa divulgação nativa (`details`/`summary`), abre automaticamente quando contém a rota ativa e pode ser aberto deliberadamente pelo usuário.

As URLs, controllers, actions, policies e regras por perfil foram preservadas. Perfis restritos continuam recebendo suas listas específicas. A busca redundante dentro da sidebar foi removida; a marca agora exibe apenas InovaGED e Gestão Documental.
