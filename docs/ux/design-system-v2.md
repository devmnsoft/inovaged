# Design System v2

O sistema usa tokens locais para marca, semântica, superfície, texto, espaçamento, raio e sombra. As camadas seguem a ordem: tokens, reset, tipografia, layout, navegação, componentes, formulários, tabelas, feedback, responsividade e acessibilidade. Bootstrap permanece como infraestrutura transitória; novos componentes devem usar classes `ig-*` e nunca cores inline.
