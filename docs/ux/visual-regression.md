# Regressão visual

A base deverá usar tolerância perceptual, nunca igualdade de pixels. Os cenários devem falhar para documento vazio, CSS ausente, overflow global, sidebar sobreposta, topbar fora do viewport, ícones substituídos por caracteres e modal inacessível. Baselines não foram gerados porque o SDK/runtime da aplicação não está disponível neste ambiente.
