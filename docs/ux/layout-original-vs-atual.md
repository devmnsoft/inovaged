# Layout original versus atual

A análise cobriu os templates e assets que compõem Login, Dashboard, GED Explorer, Administração, Usuários, Busca Hospitalar, Empréstimos, Protocolos, Classificação, Temporalidade, Guarda Física, Assinaturas, Continuidade e Meu Perfil.

Para todas as telas, a referência usa azul/verde e superfícies brancas; a main adicionava marinho e cinzas azulados. A estrutura antiga era mais direta, enquanto a atual preserva funcionalidades novas mas fragmenta a percepção com camadas e cards. Devem ser preservados ViewModels, rotas, autorização, acessibilidade, continuidade e prontidão. A decisão comum é manter o HTML funcional recente sob o tema Classic, sidebar em seis grupos, topbar de 62 px, conteúdo até 1600 px e componentes neutros.

A captura renderizada autenticada nas cinco resoluções não foi executada: credenciais, tenant e banco de homologação não estão disponíveis no ambiente. Nenhuma evidência fictícia foi produzida.
