# Contrato de cores

| Papel | Valor |
|---|---|
| Azul principal | `#2563eb` |
| Azul hover | `#1d4ed8` |
| Azul apoio | `#3b82f6` |
| Verde de identidade | `#22c55e` |
| Verde semântico | `#16a34a` |
| Fundo | `#f6f8fc` |
| Superfície | `#ffffff` |
| Texto | `#0f172a` |
| Sidebar neutra | `#0f172a` |

O gradiente institucional é exclusivamente `linear-gradient(135deg, #2563eb 0%, #22c55e 100%)`. `#071426`, `#0b1f3a`, `#12325a` e `#19477c` deixam de participar do tema canônico. Roxo e ciano não são cores de marca.
