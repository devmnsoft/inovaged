# Homologação responsiva

Contratos estáticos cobrem breakpoints de 992 px e 576 px, offcanvas, conteúdo flexível e bloqueio de overflow horizontal global. As resoluções 360×800, 390×844, 430×932, 768×1024, 1024×768, 1366×768, 1440×900 e 1920×1080 ainda exigem execução browser real; não foram declaradas homologadas neste ambiente.
