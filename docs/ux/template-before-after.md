# Template antes e depois

| Área | Antes (baseline) | Restaurado |
|---|---|---|
| Sidebar | grupos recolhíveis, controle de collapse | 260 px, branca, plana, scroll interno e rodapé |
| Topbar | breadcrumb, busca global, sino, assistente e ajuda | menu mobile, título, subtítulo, ação principal e usuário |
| Layout | claims e JavaScript inline | composição curta com contexto tipado |
| Feedback | composição duplicada | uma camada de toast e uma confirmação |
| Mobile | offcanvas sem fechamento explícito | fechamento após navegação e retorno de foco |
| Login | painel institucional já funcional na baseline | preservado sem redesenho |
